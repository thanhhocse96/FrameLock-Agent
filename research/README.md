# research — kho prompt text + phân tích

> **raw = text prompt, không phải ảnh/video.** Mỗi nhánh (ảnh/video) có 3 phần: `raws/` → `digests/` → `mapping.md`.

| Nhánh | Raw | Digest | Index |
|-------|-----|--------|-------|
| `images/` | `images/raws/` | `images/digests/` | `images/mapping.md` |
| `videos/` | `videos/raws/` | `videos/digests/` | `videos/mapping.md` |

Tra cứu digest: đọc `mapping.md` trước, không glob mò. Schema chi tiết: `.context/modules/research-images.md`, `.context/modules/research-videos.md`.
